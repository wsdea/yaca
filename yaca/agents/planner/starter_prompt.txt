# Tool Use Formatting

Tool uses are formatted using XML-style tags. You may call one or more tools, if you they don't depend of the result of each other. Here's the format to follow strictly:

## For a single tool call:
<yaca_tool name="tool_name1">
<parameter1_name>value1</parameter1_name>
<parameter2_name>value2</parameter2_name>
...
</yaca_tool>

## Example for multiple tool calls

<yaca_tool name="tool_name2">
<files>
- README.md
- .gitignore
</files>
</yaca_tool>
<yaca_tool name="update_todo">
<todo_list>
[
{"item": "Implement feature X", "status": "pending"},
{"item": "Implement feature Y", "status": "pending"}
]
</todo_list>
</yaca_tool>
